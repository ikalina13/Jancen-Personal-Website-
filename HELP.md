# Portfolio Setup Instructions

## How to Edit
To customize your portfolio, you only need to edit **ONE** file:
- **`src/portfolioData.js`**: Open this in VS Code to change your name, about description, skills, projects, and social links.

## How to Run
1. Open your terminal in the `cyberpunk-portfolio` folder.
2. Run `npm install` (if you haven't already).
3. Run `npm run dev` to start the local development server.
4. Open the link shown in the terminal (usually `http://localhost:5173`).

## Troubleshooting (White Screen)
If you still see a white screen:
- Ensure you have run `npm install`.
- Check the terminal for any errors.
- Try a different browser (Chrome or Edge are recommended).
- The "white screen" often means the background hasn't loaded or there's a JavaScript error. I have updated the code to be more robust.
