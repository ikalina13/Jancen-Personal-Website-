# My Personal Website

Welcome to my personal website! This project was built using React and Vite as part of my journey in web development and my participation in Hack Club's Macondo event.

## About Me

Hi! I'm Jan, a student from the Philippines who enjoys programming, electronics, and building creative projects. I'm interested in web development, Arduino, Raspberry Pi, and creating technology that solves real-world problems.

## Features

* Responsive design for desktop and mobile devices
* Modern user interface built with React
* Fast performance powered by Vite
* Sections for projects, skills, and personal information
* Easy to customize and expand

## Tech Stack

* React
* Vite

## Development Process

This website was developed using modern web technologies, with Gemini CLI assisting in brainstorming ideas, generating code suggestions, debugging, and improving the overall development workflow.

## Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
